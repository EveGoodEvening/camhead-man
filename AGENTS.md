# AGENTS.md

Project: 3D urban 志怪 exploration / puzzle game whose protagonist is a man with a surveillance camera for a head. three.js (WebGL) + TypeScript + Vite. All in-game text is Simplified Chinese.

## Toolchain
- three `0.186.x`, `@types/three` `0.186.x`, vite `8.x` (rolldown-based), TypeScript `7.x` (native `tsc`), playwright `1.63.0` (browsers cached in `~/.cache/ms-playwright/chromium-1243`).
- `npm run build` = `tsc --noEmit && vite build`.
